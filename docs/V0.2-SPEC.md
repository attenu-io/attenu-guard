# attenu-guard v0.2 — Implementation Contract

*The single source of truth for the v0.2 build. Every module below is implemented
against this contract. Derived from DEVX-REVIEW.md and the Internet-Draft
(draft-asor-wimse-agent-delegation-chain-00). Read both for rationale; this file
is the precise interface.*

## Hard constraints (non-negotiable)

- **Core is stdlib-only.** No third-party runtime imports in `reasons.py`,
  `ceilings.py`, `authority.py`, `chain.py`, `guard.py`, `audit.py`, `scenarios.py`.
  Optional extras (`cryptography` for Ed25519, `PyYAML`, `langgraph`) must be
  imported lazily and degrade gracefully — never at module top level of the core.
- **Every test runs with bare `python3`** (no pip). `tests/run_properties.py` and
  `tests/red_team.py` must stay green with zero installs.
- **The safety model does not change.** Attenuation is still a lattice meet that
  can only narrow; the v0.1 red-team invariants must all still pass. v0.2 changes
  ergonomics, explainability, extensibility, and adds the wire format.
- **Backward-compat shims for one minor version.** `Guard.root/spawn/kill` remain
  as thin deprecated aliases emitting `DeprecationWarning`.

class ReasonCode:                     # string constants (stable, machine-readable)

    limit: object = None
    requested: object = None

    def to_dict(self) -> dict: ...

    allowed: bool
    reasons: tuple[Reason, ...] = ()
    determining_node: str | None = None

## ceilings.py

A `Ceiling` is a typed bound that can (a) check a request context and (b) narrow
against another ceiling of its own type. Unknown/unhandled ceiling types must
**fail closed**.

```python
@runtime_checkable
class Ceiling(Protocol):
    key: str                                  # e.g. "max_rows"
    def permits(self, ctx: Mapping) -> Decision: ...
    def narrow(self, other: "Ceiling") -> "Ceiling": ...   # returns the MORE restrictive
    def subsumes(self, other: "Ceiling") -> bool: ...       # self is >= permissive than other
    def to_wire(self) -> dict: ...            # -> constraint object per the I-D
    @classmethod
    def from_wire(cls, d: dict) -> "Ceiling": ...

# built-ins (all frozen dataclasses implementing Ceiling):
RowLimit(max_rows: int)          key="max_rows"      ctx uses ctx["rows"]
SpendCap(max_spend: float)       key="max_spend"     ctx uses ctx["spend"]
CallLimit(max_calls: int)        key="max_calls"     ctx uses ctx["calls"]
EgressRank(level: str)           key="egress"        order none<internal<any; ctx["egress"]
Allow(one_of: frozenset)         key + ctx configurable   membership
Deny(not_one_of: frozenset)      key + ctx configurable   anti-membership
Prefix(prefix: str)              key + ctx                string prefix

# registry — extension seam
register_ceiling(key: str, cls: type)         # map a wire "type"/key to a Ceiling class
ceiling_from_wire(d: dict) -> Ceiling          # fail-closed: unknown key -> _UnknownCeiling
                                               # whose permits() ALWAYS denies (UNKNOWN_CONSTRAINT)
```

`narrow` semantics: min for numeric caps; set-intersection for Allow; set-union
for Deny; min-rank for EgressRank. `subsumes`: the inverse (self admits a superset
of what other admits).

## authority.py

```python
@dataclass(frozen=True)
class Authority:
    scopes: frozenset[str]                    # "crm.read", wildcard "crm.*"
    ceilings: tuple[Ceiling, ...] = ()        # LIST of typed ceilings (not a dict)
    ttl: int | None = None                    # seconds
    # construction accepts an iterable of Ceiling; normalize to a tuple keyed by .key

    def covers_scope(self, requested: str) -> bool: ...          # wildcard-aware (v0.1 logic kept)
    def meet(self, other: "Authority") -> "Authority": ...       # THE attenuation (lattice GLB)
    def is_narrower_than(self, other: "Authority") -> bool: ...  # the subsumption relation C <= P
    def permits(self, scope: str, ctx: Mapping) -> Decision: ... # scope + all ceilings; aggregates the reasons
    def to_wire(self) -> dict:  ...            # -> {"scopes":[...], "constraints":[...], "ttl":...}
    @classmethod
    def from_wire(cls, d) -> "Authority": ...
    # keep to_dict/from_dict as aliases of to_wire/from_wire for continuity
```

`meet` rules (must preserve v0.1 fixed behavior):
- scopes: wildcard-aware intersection; a wildcard granted by BOTH sides survives
  (v0.1 pruning fix); never widens.
- ceilings: for each key present on EITHER side, take `narrow`; **a ceiling on one
  side only is carried through** (so the child is bounded wherever either parent
  or request bounds it). Result: child ceilings key-set = union; each = narrow.
- ttl: min (ignoring None).

`is_narrower_than(P)` (self <= P) — TRUE iff:
1. every scope of self is covered by P (wildcard-aware);
2. for every ceiling in P there is a ceiling of the same key in self that P
   `subsumes` (i.e. self is at least as restrictive); **a ceiling in P absent in
   self => False** (self unbounded there); and
3. self.ttl is not None and (P.ttl is None or self.ttl <= P.ttl).
This is exactly the wire subsumption relation — the library relation and the
token relation MUST be identical.

## chain.py

Same responsibilities as v0.1 (Node, Chain, revocation cascade, ttl via injectable
clock, per-chain HMAC integrity seal) — but Node.authority is the new Authority,
and `add_child` uses `meet`. Denials that used to raise now flow through Decision
where reached via check(); structural failures at delegation (depth/fanout/
revoked/expired/integrity) still raise `AuthorityError` from `delegate()`.
`MonotonicClock`, `is_expired`, `verify_integrity`, `consume` retained.

## guard.py

```python
class Guard:
    @classmethod
    def issue(cls, agent_id, authority, task="root", *, chain_id="chain",
              max_depth=6, max_fanout=16, audit_path=None, clock=None,
              strict_metering=False) -> "Guard": ...
    # deprecated alias: root = issue  (DeprecationWarning)

    def delegate(self, agent_id, request: Authority, task: str) -> "Guard": ...
    # deprecated alias: spawn = delegate

    def revoke(self, node_id: str | None = None) -> list[str]: ...
    # deprecated alias: kill = revoke

    def check(self, scope: str, *, context: Mapping | None = None,
              metered: bool = False, tool: str | None = None) -> Decision: ...
    #   returns a Decision (does NOT raise on denial). Logs allow/deny to audit.
    def enforce(self, scope: str, **kw) -> None: ...
    #   calls check(); raises AuthorityDenied(decision) if not allowed.
    def would_allow(self, scope: str, **kw) -> Decision: ...
    #   pure dry-run: same as check() but writes NOTHING to the audit log.

    def is_narrower_than(self, parent: "Guard") -> bool: ...   # convenience over authorities
    def audit_log(self) -> AuditLog: ...
    def graph(self) -> dict: ...
    @property
    def authority(self) -> Authority: ...
    @property
    def node_id(self) -> str: ...

# context bag replaces per-quantity kwargs:
#   node.check("crm.read", context={"rows": 5000, "egress": "none"}, tool="sql")
# back-compat: check() also accepts rows=/spend=/egress= and folds them into context,
#   emitting a DeprecationWarning.

class AuthorityDenied(Exception):    # raised only by enforce()
    def __init__(self, decision: Decision): self.decision = decision; ...
```

`AuthorityError` (structural, from delegate/issue) and `AuthorityDenied` (policy,
from enforce) are DISTINCT — denied is not errored.

## wire.py  (standards alignment — the I-D reference implementation)

Implements the Delegation Token and offline verification from the draft. Signer is
**pluggable**; ship a stdlib HMAC test signer (default, offline) and an Ed25519
signer requiring the optional `cryptography` extra.

```python
class Signer(Protocol):
    alg: str
    def sign(self, signing_input: bytes) -> bytes: ...
    def verify(self, signing_input: bytes, sig: bytes, key_id: str) -> bool: ...

class HS256TestSigner(Signer): ...      # stdlib hmac; alg="HS256"; FOR TESTS/DEV ONLY
class Ed25519Signer(Signer): ...        # lazy-imports cryptography; alg="EdDSA"

def serialize(guard_or_node, signer: Signer) -> str:
    # emit a Delegation Token: JWT-shaped (header.payload.sig, base64url) carrying
    #   authorization_details (from Authority.to_wire), del_depth, del_max_depth,
    #   par_hash (sha256 of parent signing input) for depth>0, exp, iat, jti, cnf(optional).
def load(tokens: list[str], root_pubkeys, signer: Signer) -> "VerifiedChain":
    # run the offline verification algorithm (draft §Verification): signature,
    #   par_hash byte-commitment, del_depth, subsumption via Authority.is_narrower_than,
    #   monotonic exp, (cnf/DPoP out of scope for v0.2 lib test), status (skip).
    # returns a VerifiedChain exposing the leaf Authority; raises WireError on any failure.
```

`serialize`/`load` MUST round-trip an Authority losslessly, and `load` MUST reject
the adversarial vectors (widened scope, exceeded ceiling, spliced par_hash, depth
overflow, non-monotonic exp). Provide these as `tests/vectors/*.json`.

## scenarios.py  (DevX + interop harness)

Declarative runner. Accept JSON natively (stdlib); accept YAML if `yaml` importable.
Schema (JSON mirror of the DEVX-REVIEW YAML):

```json
{ "root": {"agent":"planner","authority":{"scopes":["crm.read","crm.write"],
            "ceilings":[{"key":"max_rows","max":1000}],"ttl":3600}},
  "delegations": [ {"as":"summarizer","attenuate":{"scopes":["crm.read"],
            "ceilings":[{"key":"max_rows","max":100}]}} ],
  "assertions": [
    {"node":"summarizer","check":{"scope":"crm.read","context":{"rows":50}},"expect":"allow"},
    {"node":"summarizer","check":{"scope":"crm.write"},"expect":"deny","because":"scope_not_granted"},
    {"node":"summarizer","check":{"scope":"crm.read","context":{"rows":5000}},"expect":"deny","because":"ceiling_exceeded"} ] }
```

`run_scenarios(path) -> ScenarioResult` with pass/fail per assertion, checking BOTH
the boolean and (when `because` given) the top reason code. `--coverage` prints
which reason codes were exercised.
